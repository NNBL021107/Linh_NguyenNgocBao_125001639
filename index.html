Giới thiệu

Tôi là Nguyễn Ngọc Bảo Linh, hiện đang là sinh viên CNTT năm hai tại Đại học Lạc Hồng (LHU). Với niềm đam mê đặc biệt dành cho lập trình và thiết kế web, tôi luôn nỗ lực trau dồi tư duy giải thuật, viết mã nguồn sạch (Clean Code) và tạo ra giao diện chuẩn ngữ nghĩa HTML5, hiện đại và thân thiện với người dùng.

  • Trường: Đại học Lạc Hồng (LHU)
  • Chuyên ngành: Công nghệ Thông tin
  • Địa chỉ: TP. Biên Hòa, Tỉnh Đồng Nai
  • Sở thích: Lập trình Web, Python, Arduino IoT
Chuyên môn

Kỹ năng lập trình

HTML5 / CSS3

Semantic HTML5, CSS Grid, Flexbox, CSS Variables, Responsive Design và hiệu ứng chuyển động mượt mà.

Python

Cú pháp căn bản, lập trình hướng đối tượng (OOP), xử lý tệp dữ liệu JSON/CSV và viết ứng dụng dòng lệnh CLI.

SQL & Cơ sở dữ liệu

Thiết kế lược đồ quan hệ, truy vấn dữ liệu CRUD, kết nối cơ sở dữ liệu MySQL và SQLite.

JavaScript (ES6+)

Thao tác DOM, xử lý sự kiện tương tác, hàm bất đồng bộ Fetch API và xây dựng tính năng người dùng.

Arduino / IoT

Lập trình vi điều khiển với C/C++, mô phỏng mạch điện tử Tinkercad, cảm biến và đèn tín hiệu thông minh.

Git & GitHub

Quản lý phiên bản mã nguồn, commit chuẩn mực, làm việc theo nhánh và lưu trữ đồ án học tập.
